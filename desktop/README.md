# Nautilus 桌面端

**Alpha 0.0.2-alpha.1 · `0.0.2-alpha.1`**

Java Swing 文本聊天客户端，通过本地 Rust 子进程调用 DeepSeek、OpenAI、Gemini 和 Claude。界面使用统一深色侧栏、连续消息卡片和可操作的 Markdown 代码块。

[返回项目首页](../README.md) · [隐私与密钥](PRIVACY.md) · [测试](../docs/TESTING.md) · [发布说明](../docs/releases/v0.0.2-alpha.1.md)

## 启动与首次配置

需要 macOS / Linux 图形桌面、Rust / Cargo、JDK 17+。首次 Rust 构建可能联网下载依赖；Markdown JAR 已随源码提供，不需要安装 Maven、JavaFX 或 IntelliJ。

在工程根目录运行：

```bash
./desktop/run.sh
```

启动脚本编译 Rust bridge 和 Java 源码，再打开窗口。若文件没有执行权限，使用 `bash desktop/run.sh`。源码包不是可直接双击运行的安装器。

每次启动会出现“API 密钥与隐私”：

1. 填写自己要使用的平台 API key，其他平台可留空。
2. 阅读并确认明文存储与第三方调用说明，点击保存。
3. 关闭设置窗口，在侧栏选择已配置的平台并开始对话。

已有密钥不会显示或预填。留空表示保留原值；删除请使用对应平台的删除按钮。设置也可随时从侧栏底部的 **⚙️ 设置 → API 密钥与隐私** 重新打开。

## 模型选择与聊天

| 操作 | 行为 |
| --- | --- |
| 点击 OpenAI | 切换到对应平台，保留本轮会话历史 |
| 点击 DeepSeek / Gemini / Claude 卡片 | 在侧栏内展开分支；约 220 ms 缓动，箭头旋转和悬停渐变 |
| 选择 Flash / Argon / 自动 | 切换预设并自动收起；卡片显示最近确认的分支 |
| 点击外部 / Esc | 收起子模型分支，不发起模型请求 |
| 方向键 / Enter | 导航并确认子模型选项；Space 也可操作按钮 |
| Enter / 发送 | 发送当前问题 |
| Shift + Enter | 输入换行 |
| 新对话 | 清空当前历史、点赞建议、代码修改和批注，保留当前模型 |

模型区域在空间不足时可滚动，底部 API 设置保持可见。请求在后台执行；等待期间可编辑下一条草稿，但发送、切换模型、新对话和密钥设置暂时禁用。

失败请求在聊天区显示错误，可以继续尝试；失败轮次不加入后端对话历史。模型切换只有在成功后才更新选中状态。API key 是否已配置不等于服务端已验证有效。

Gemini 的模型 ID、自动规则与搜索边界见[项目首页](../README.md)。本版本仍为完整回答后一次显示，没有流式输出和取消请求按钮。

## 阅读与复制 Markdown

支持标题、粗体、斜体、删除线、有序/无序及嵌套列表、引用、分隔线、代码、表格和 HTTP/HTTPS 链接。

- **复制全文**：复制模型原始 Markdown，包括原始代码块。
- **选择文本**：可局部选择并使用系统复制快捷键。
- **链接**：仅在主动点击时打开系统浏览器；图片仅显示替代文本。
- **代码排版**：保留缩进和换行，使用等宽字体；长行按消息宽度折行，不执行代码。
- **原始 HTML**：作为文字处理，不作为脚本或嵌入网页执行。

## 代码修改、批注与后续提问

每个围栏/缩进代码块有当前会话内的编号，例如 `C1`，顶部提供三个按钮：

| 按钮 | 用途 |
| --- | --- |
| 复制 | 复制当前本地代码版本，不包含 Markdown 围栏 |
| 修改 | 编辑代码和批注；保存后显示本地版本，原始模型回复仍保留 |
| 批注 | 选取代码、记录问题或修改意图；“引用所选代码行”会填入行号范围 |

在弹窗中取消不会保存草稿。清空批注可以删除它；“恢复原代码并清空批注”会取消该代码块的自动增强。批注中的行号是保存时的文本引用，后续改动代码不会自动重定位行号。

示例追问：`请根据 C1 的批注修改，并解释修改原因。`

- 显式提到代码编号时，会附带对应当前代码，即使还没有修改或批注。
- 对已经修改/批注的代码，本地规则会根据标识符、中文批注重合或“这段代码”等指代判断相关性。
- 输入区显示本次附带的编号；取消“附带”可仅发送当前输入。
- 最多附带最近的 3 个相关块；每块代码最多 12,000 个 Java 字符单位，代码合计最多 24,000，批注每块最多 2,000。截断会在界面及上下文中标明。
- 已在之前发送的内容仍属于后端历史。取消本轮附带或删除本地批注不会撤回旧请求；清空历史请使用“新对话”。

## 点赞与下一句建议

点赞会根据该回复是否包含代码，生成一条可编辑的后续问题建议。这是简单的本地规则，不是个性化预测模型，也不用于训练。

点击“填入建议”可放入输入区；已有草稿会保留，建议附加在后面。你可以修改后再发送。点赞、填入建议本身不调用平台 API，也不会自动发送消息。再次点击可取消点赞。

## 密钥、历史与账号

桌面端通过本机认证 HTTP 通道把 key 交给 Rust（保留标准输入管道兼容入口），保存到当前操作系统用户的配置目录：

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Nautilus/.env` |
| Linux | `$XDG_CONFIG_HOME/Nautilus/.env`，默认 `~/.config/Nautilus/.env` |
| 开发/测试覆盖 | 设置 `NAUTILUS_PROFILE_DIR` 为独立目录 |

目录权限 `0700`、文件权限 `0600`；key 按要求明文保存，输入框遮蔽显示。这里的“账号”是系统账号，不是新增的云端账号。同一系统账号下的其他程序仍可能读到明文。

桌面端忽略工程 `.env` 和继承的 API key。保存或删除密钥会清空会话，避免沿用旧凭据；删除全部密钥会移除该用户配置文件。当前对话、点赞、代码编辑和批注只保存在进程内存，关闭后不自动恢复。

模型调用将问题与历史交给所选平台；切换平台会沿用历史。更多处理范围及删除限制见[隐私说明](PRIVACY.md)，本应用不宣称已获得 GDPR 合规认证。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 找不到 `javac` | 安装完整 JDK 17+，确保 `java` 与 `javac` 在 PATH 中 |
| 找不到聊天服务 | 从工程根目录运行 `desktop/run.sh`，由脚本构建 `target/debug/nautilus-chat-bridge` |
| 提示需要图形桌面 | 桌面端不能在无显示环境中启动；使用 CLI 或无界面测试脚本 |
| 401 / 403 / 配额错误 | 在设置中检查对应平台 key，并核对平台账号权限、区域与额度 |
| 模型不存在 | 核对当前预设及平台文档；Gemini 菜单不会读取自定义 `GEMINI_MODEL` |
| 请求失败或超时 | 检查网络/代理；可再次提问，或切换到其他已配置的平台 |
| 没有搜索来源 | 启用 Google Search 不保证每次搜索；模型需实际使用工具且返回来源数据 |
| 重启后聊天不见了 | 当前 Alpha 不保存聊天记录，这是本版本的已知限制 |

## Mixture 测试版

点击 Mixture 打开两列组队面板，将左列模型卡片拖到右列规划、执行、复核、汇总区域，确认后参与协作。取消不改变当前模型。暂不启用预算限制，不需要价格配置；未配置密钥的模型不可选。协作进度及故障接替显示在对话中。

## 设置与界面语言

侧栏底部 **⚙️ 设置** 向上平滑展开，包含 API 密钥与隐私、语言 / Language、退出。语言子菜单支持 🇨🇳 简体中文、🇭🇰 繁體中文、🇭🇺 Magyarország、🇺🇸 English；主界面和操作控件即时切换，偏好保存在本机配置目录的 `language.txt`，下次启动恢复。语言设置仅影响界面，不翻译或重写消息、模型回复、代码、批注或草稿；来自后端的原始诊断仍保留原文。

菜单支持 Tab、上下方向键和 Enter；Escape 先收起语言子菜单，再收起设置，点击菜单外也会关闭。退出项悬停及键盘聚焦时渐变为品红色，离开后平滑恢复；退出会关闭桌面窗口及其 Rust 后台进程。模型请求期间仍可切换语言或退出，密钥设置保持禁用。

## DeepSeek 子模型

DeepSeek 卡片可平滑展开两个选项：V4.1-Flash、V4-Pro。支持上下方向键、Enter、Escape 和点击外部收起；切换成功后才确认选中状态，请求期间禁用选择。两个预设共用同一份 DeepSeek API 密钥，分别调用 `deepseek-flash` 和 `deepseek-v4-pro`。

Mixture 组队面板中直接列出 DeepSeek V4.1-Flash / V4-Pro、OpenAI、Gemini Flash / Argon / Auto、Claude Opus 5.5 / Fable 5.1 / Sonnet 5.5 / Haiku 5.5 卡片，无需展开子菜单。每个平台选择一个子模型，将同平台另一版本拖入时自动替换；Gemini Auto 按本轮任务路由，混合模式仍不启用联网搜索。

窗口底部固定提示：“Mixture模式下，突然更换到独立模型，上下文记忆暂时无法生效。”混合会话与独立会话继续保持隔离。

## 流式进度与聊天反馈

默认使用本机 HTTP SSE 事件流，Java 消费 `notice`、`progress` 和最终 `result`，心跳保持连接，断流不会当作成功回复。阶段记录显示 `[Planner / Worker / Reviewer / Summarizer · 自定义角色 | 实际模型]`、节点状态及 `HH:mm:ss` 耗时。已完成记录保留，错误与退出停止动态气泡；聊天和代码复制成功后有动画与短暂确认。设置 `-Dnautilus.transport=stdio` 可用于旧通信入口调试。

Planner 的节点数来自实际解析的结构化计划（最多6项），Worker 依次产出各节点结果，再汇总最终回复。结构无效时不显示伪造的节点数。这里的 SSE 是 Rust 到桌面的调度进度流；模型正文仍在完整返回后渲染为 Markdown。

## Claude 子模型与四平台协作

在 **⚙️ 设置 → API 密钥与隐私** 的 **Claude · Anthropic** 栏填写自己的 API key。四个子模型共享该密钥；留空保留已有配置，支持单独删除。桌面端不会使用工程 `.env` 或继承的 `ANTHROPIC_API_KEY`。仅配置 Claude 时会默认选中 Opus 5.5。

侧栏 Claude 卡片平滑展开四个分支。确认切换前保留原选中项；失败时不改变会话和已确认选择，请求期间禁止切换。密钥表单、侧栏及协作成员区支持滚动，四平台与展开后的子菜单均可访问；协作分工说明换行显示。

Mixture 每个平台选择一个子模型，Claude 可单独汇总，也可参与两至四平台团队。各成员的角色与同阶段顺序由用户拖动卡片指定，Claude 不固定负责汇总；仅在用户允许时跨职责接替失败任务。真实模型 ID、用户角色名、阶段和耗时沿用 SSE 进度气泡。

原生 API 模型映射见[项目首页](../README.md)。尚未执行真实付费 Claude API 验证；模型访问权限、配额与费用取决于用户的 Anthropic 账号。

## 两列拖拽分工

左列为按平台分组的十个模型卡片，右列为规划、执行、复核、汇总四个区域。首次打开角色区为空，直接拖入卡片即可分配，没有下拉菜单、角色名称或具体目标输入框。

- **分配 / 更换职责**：拖入角色区或在角色区之间移动。
- **调整顺序**：在执行或复核区域内拖动，按插入位置排序。
- **移除**：拖回模型列、点击卡片 ×，或聚焦卡片后按 Delete。
- **更换子模型**：拖入同平台另一版本，自动替换原分配。
- **替换规划 / 汇总**：这些区域最多一个模型，拖入新卡片即替换旧卡片。规划可以为空，汇总必须有一个。
- **键盘与点击**：先选择模型，再点击角色标题；数字键 1 / 2 / 3 / 4 对应规划 / 执行 / 复核 / 汇总。

未配置 key 的卡片灰显不可拖放。拖动显示模型预览、目标区高亮与插入线，放下后短暂反馈。两个区域各自滚动，并按视口宽度布局；最小弹窗尺寸为 940 × 740。

点击“开始协作”才将模型、角色及顺序提交给后端；取消拖动或取消窗口保留原团队。重新打开恢复本次进程内已确认的分工，历史表单中的自定义文字不再作为隐藏目标沿用。角色工作指令由程序生成，无需填写。跨职责失败接替默认关闭，可通过底部复选框开启。

完整 SSE 端口联调及真实付费 API 沿用既有验证边界。离线检查覆盖 Swing 传输处理器与真实 Java/Rust 管道，系统原生鼠标拖拽手势仍需在图形桌面验证。


### 团队推荐与动画

Mixture 右上角“推荐”在面板内展开两张卡片，不新增下拉框或目标表单。“专家团队”使用 V4-Pro / Argon / Fable，“推荐团队”使用 V4.1-Flash / Flash / Sonnet；两套均沿用当前唯一的 OpenAI 入口（默认 gpt-5-mini，遵循 OPENAI_MODEL）。未配置密钥的平台自动跳过，保证至少一个汇总成员；无密钥时不可应用。预设仅编辑草稿，可继续拖换角色，保留接替选项，确认才提交。详细映射和来源见[项目 README](../README.md#mixture-混合模式)。

`Motion.java` 集中管理 16ms 帧间隔、220ms 可反向展开、悬停渐变和 450ms 操作反馈。设置使用固定中心的矢量齿轮；按钮文字与背景同步按下；悬停不再引发设置排版。菜单、按钮、Mixture、进度移除时释放动画，运行中的进度重显时恢复，已完成记录保持静止。`MixturePresets.java` 维护建议子模型及缺少密钥时的分工，不执行 API 调用或实时价格查询。
