# Nautilus Alpha 0.0.2-alpha.2

**版本：`0.0.2-alpha.2` · 标签：`v0.0.2-alpha.2` · 类型：Pre-release**

本版本延续四平台对话、Mixture 协作、主题切换、历史对话和联网搜索，完善 Windows 构建流程，新增自动生成 MSI 的 GitHub Actions 工作流。

[项目首页](../../README.md) · [更新内容](../../更新内容.md) · [Windows 指南](../../desktop/WINDOWS.md) · [发布流程](../RELEASING.md)

## 本次更新

- 推送到 `main`／`master`、推送 `v*` 标签或向主分支提交 Pull Request 时自动构建 Windows x64 MSI，也可手动运行。
- 工作流自动准备完整 Temurin JDK 17、Python、Rust MSVC 和 WiX 3；构建前执行原生 Rust 和桌面回归，构建后检查随附运行时、MSI 数据库及 SHA-256。
- Windows 打包默认使用 MSI，保留 `--installer-type exe`；构建机支持 JDK 自动发现及 `--jdk-home`，统一使用同一套 Java 工具。
- 安装包包含 Java 运行时、Rust 后端及 Nautilus 图标，使用当前账户安装方式。构建输出继续位于工程之外。
- 同步 Cargo 版本、发布草稿默认标签、文档及安装包名称，保留旧版本发布说明。

## 下载与构建

在 GitHub **Actions → Windows MSI installer → 成功运行 → Artifacts** 下载构建产物，解压后可获得：

- `Nautilus-0.0.2-alpha.2-Windows-x64-Setup.msi`
- `Nautilus-0.0.2-alpha.2-Windows-x64-Setup.msi.sha256`

源码发布附件使用 `nautilus-0.0.2-alpha.2-source.zip`、`nautilus-0.0.2-alpha.2-source.tar.gz` 及 `SHA256SUMS`。MSI 工作流上传 Actions 产物，不自动创建 Release。

## 验证边界

最近本地验证记录：65 项 Rust 测试、Rust 格式与 Clippy 检查、14 组桌面回归、17 项发布回归、12 项 Windows 打包回归，以及发布清单和工作流 YAML 配置检查通过。发布回归包含远端历史文件保留、Windows 默认编码模拟及已有标签下的仅推送修复流程。Windows 原生安装、升级、卸载及图形桌面仍需实机验证。实际 MSI 产物以成功的 Actions 运行结果为准；未执行真实付费模型 API 验证。

发布状态以 GitHub 上的提交、版本标签、Releases 和对应 Actions 运行结果为准。
