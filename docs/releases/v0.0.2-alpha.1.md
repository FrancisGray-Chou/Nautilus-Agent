# Nautilus Alpha 0.0.2-alpha.1

**版本：`0.0.2-alpha.1` · 标签：`v0.0.2-alpha.1` · 类型：Pre-release**

本版本扩展 Claude 模型接入、四平台 Mixture 协作和动态桌面交互。本文件记录本次预发布的更新内容及验证边界；实际发布状态以 GitHub Releases 为准。

[项目首页](../../README.md) · [完整更新内容](../../更新内容.md) · [测试说明](../TESTING.md) · [发布流程](../RELEASING.md)

## 新增与改进

- Claude 原生 Messages API，提供 Opus 5.5、Fable 5.1、Sonnet 5.5、Haiku 5.5 四个预设，使用用户自己的 Anthropic API key。
- Claude 密钥支持独立保存、替换、删除及重载；侧栏提供动态折叠菜单，Mixture 使用直接可拖动的子模型卡片。
- Mixture 支持 DeepSeek、OpenAI、Gemini、Claude 一至四平台协作，每个平台选择一个子模型。
- Mixture 加入内联“推荐”，专家团队优先能力、推荐团队兼顾成本；仅使用已配置平台，草稿可继续拖拽调整，确认后提交。
- 修复设置齿轮偏心、按钮按下位移与动画残留；统一帧间隔、展开缓动、悬停渐变、焦点反馈及生命周期清理。
- Mixture 使用模型与角色两列布局，拖动卡片到规划、执行、复核或汇总区；支持排序、替换和移除，没有下拉框或具体目标表单，跨职责接替由用户主动开启。
- 执行成员按目标处理节点或独立工作，复核成员单独检查，指定汇总成员交付；进度同步显示用户角色名。
- Rust SSE 推送实际模型、Planner / Worker / Reviewer / Summarizer 阶段、节点状态及耗时；正文仍在完整返回后一次显示。
- ⚙️ 设置集中管理密钥、四语界面和退出；同步滚动排版、视口宽度适配及动态聊天反馈。
- Markdown 全文及代码复制、本地代码修改、行号批注和相关追问上下文增强。
- 重整 README，新增中文更新说明及离线 Claude 菜单预览，修正中文文件名的发布清单检查。

## 下载与运行

| 预期附件 | 内容 |
| --- | --- |
| `nautilus-0.0.2-alpha.1-source.zip` | 源码、锁文件、随附 Markdown JAR、文档和检查脚本 |
| `nautilus-0.0.2-alpha.1-source.tar.gz` | 相同内容，Unix 归档格式 |
| `SHA256SUMS` | 两个归档的 SHA-256 校验值 |

当前提供源码构建方式，尚无预编译安装器、签名应用或自动更新包。需要 macOS / Linux、Rust stable 及 JDK 17+。解压后在工程根目录运行：

```bash
./desktop/run.sh
```

在 **⚙️ 设置 → API 密钥与隐私**填写自己的平台 key。无需同时配置全部平台。CLI 按 `.env.example` 配置后运行 `cargo run --locked`，服务选项 `4` 为 Claude。

## 数据与已知限制

- 桌面 API key 按现有说明明文保存在当前操作系统账号的私有配置中；保存或删除密钥会清空会话。
- 单模型之间切换沿用历史，Mixture 与独立模型会话分开保留，切换时暂不互传上下文。
- 聊天、点赞、代码编辑与批注不自动持久化；没有停止生成按钮或自动上下文裁剪。
- 不支持文件、图像、音视频输入及完整自定义工具执行。
- Mixture 当前按阶段接力执行，暂不启用并发模型调用或预算保护；桌面可为四平台成员开启联网搜索。
- SSE 传输调度事件，尚非上游逐 Token 正文输出。
- 未使用真实付费 key 完成四平台端到端验证。平台权限、区域、模型可用性、配额与费用取决于用户账号。

反馈问题时请附版本、系统、所选模型、复现步骤及脱敏错误，不要上传 API key、`.env` 或私人对话。项目级许可证尚未指定，第三方许可独立保留。
