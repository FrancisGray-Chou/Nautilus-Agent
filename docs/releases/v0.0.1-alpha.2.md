# Nautilus Alpha 0.0.1

**版本：`0.0.1-alpha.2` · 标签：`v0.0.1-alpha.2` · 类型：Pre-release**

Nautilus 是 StarSea Community 的多模型文本对话原型，使用 Rust 后端和 Java Swing 桌面端。首个 Alpha 供测试者验证聊天流程、Markdown、代码批注与模型切换，并反馈问题。

本文件为可直接放入 GitHub Release 的说明。当前仓库准备状态和实际验证结果见 `docs/RELEASING.md` 与 `docs/TESTING.md`；准备完成不代表已公开发布。

## 本次提供

- DeepSeek、OpenAI、Gemini 文本对话与连续上下文。
- Gemini Flash、Argon、自动三个分支；侧栏内动态展开选择。
- Gemini 原生 Google Search 接入，显示 API 返回的搜索词与来源。
- Markdown 渲染、全文复制、代码块复制/修改/批注。
- 相关代码上下文的可选附带、点赞后的可编辑本地追问建议。
- 按系统账号保存、替换和删除用户自己的 API key。
- CLI 数字菜单及 `/model`、`/exit`、`/quit` 命令。

## 下载与运行

附件预期为：

| 文件 | 内容 |
| --- | --- |
| `nautilus-0.0.1-alpha.2-source.zip` | 源码、锁文件、随附 Markdown JAR、文档和测试脚本 |
| `nautilus-0.0.1-alpha.2-source.tar.gz` | 相同内容，Unix 归档格式 |
| `SHA256SUMS` | 两个归档的 SHA-256 校验值 |

源码包内的 `SOURCE-MANIFEST.json` 记录版本、提交状态、文件哈希和权限。本次没有预编译安装器、签名 macOS 应用、Windows 包或自动更新程序。

需要 macOS / Linux、Rust stable 和 JDK 17+；首次构建可能下载 Rust 依赖。解压并进入目录后：

```bash
./desktop/run.sh
```

启动后填写自己的平台 API key。CLI 用户按根目录 `.env.example` 配置后运行 `cargo run --locked`。

## 数据与已知限制

- API key 以明文保存到当前操作系统用户的私有 `.env`。请先阅读包内 `desktop/PRIVACY.md`。
- 不是云端账户系统，也不代表已获得 GDPR 合规认证。
- 问题与历史发送给用户选择的平台；切换平台会沿用上下文。
- 聊天、点赞和代码批注不持久化；关闭窗口或新建对话后不恢复。
- 非流式输出，没有取消生成、自动裁剪长历史、文件/图片/音视频输入或自定义工具执行。
- 点赞建议、Gemini 自动路由及代码关联使用本地规则，可能判断不准。
- 桌面失败请求不提交本轮历史；CLI 失败时可能保留用户输入。
- 不保证每轮 Gemini 都搜索；来源显示取决于平台实际返回的数据。
- macOS Apple Silicon 完成本地离线检查；Linux 与 JDK 17 运行时需要以实际 GitHub CI 结果为准。Windows 桌面凭据功能未支持。
- 未使用真实付费 API key 完成三平台端到端测试。平台权限、可用性、配额及费用需由测试者自行核对。
